# Ozon 运费自由画板

## GUOO 2026.7.20 与数量（2026-09-17）

新增63条Ozon运价快照：俄罗斯rFBS 15、FBP 12、哈萨克斯坦12、白俄罗斯12、吉尔吉斯斯坦6、乌兹别克斯坦6。到点/到门同价归并。只读核对单价和首票费后固化在guoo_tariffs.py；运行无需Excel文件。Yandex、仓储及增值服务不是Ozon发运运费，未混入渠道。大件文字与公式存在计抛/尺寸矛盾，渠道说明记录差异，尺寸使用较小限制；使用前需承运商确认。旧画布首次打开只补入新GUOO渠道，不覆盖旧价格，保存后持久化。

## 跟卖浏览器采集（2026-09-17）

### 历史版本

每个店铺+商品内部ID独立保存报价版本。第一次导入为第1版，第二次成功导入为第2版，第1版完整报价、原始JSON及采集时间保存在history；后续依次追加，历史是平铺快照，不递归嵌套。即使内容相同，新一次导入也记录版本；同一次批量结果重复出现同商品只生成一版。既有无版本号记录按第1版升级。

跟卖卡片的“报价版本”下拉可查看完整历史报价和日期，最新版本默认展示。关闭跟卖卡片只隐藏画面，不删除最新或历史数据；通过刷新跟卖或再次导入可打开。保存失败时恢复导入前状态。失败或syncing结果不产生报价版本；成功空数组产生“无报价”的新版本，但上一版仍保留。

报价历史改为独立的 Ozon Competitor Price History 单据：每个画布+店铺+商品内部ID单独编号，一次粘贴共用批次号。同一批次重试不会重复新增；新一次粘贴保存会追加版本。原始JSON、报价、采集时间和导入时间分别存储，只读历史不覆盖。历史按50版分页加载，不自动裁剪。画布仍限2MB，单次采集导入限20MB，但累计报价历史不再占用画布空间。重新打开画布自动读取数据库最新报价；画布导出仅保留关联标记，不包含独立历史记录，备份历史需备份ERPNext数据库。旧画布内的历史在下一次保存时迁移，同一事务成功后才移除内嵌历史。

原 Cookie 按钮/弹窗已替换为“抓取跟卖”，不再接收登录凭证。旧凭证保存和服务端后台页面检查入口已移除，已有私密凭证不用于这条流程。

1. 刷新 SKU，建立或补全商品与物料卡片的对应关系。
2. 打开“抓取跟卖”，点击“复制F12命令”。仅使用当前画布卡片已有的 Ozon 商品内部 ID，按店铺+商品ID去重；服务端只核对店铺并补上 companyId，不请求全店铺商品列表。空白模拟物料及尚未取得商品ID的卡片不采集；可先刷新物料标识。需要全部商品时，手动点击“刷新 SKU”生成卡片，再复制命令。命令只有店铺标识/商品编号，没有秘钥或 Cookie。
3. 在正常登录的 `seller.ozon.ru` 页面控制台运行。命令串行读取价格接口，商品间隔1.5秒；请求超时30秒；401、403、429或非JSON验证页面停止采集，不绕过验证。跨店铺需要当前浏览器具有对应访问权限。
4. 完成时自动尝试复制结果到剪贴板；失败则使用控制台 copy，再失败下载JSON。结果仍保存在 `window.__ozfcCollectionResult`。可手动运行 `copy(JSON.stringify(window.__ozfcCollectionResult))`。采集期间勿关闭/刷新页面。
5. 将结果粘贴回来，点击“保存并加载到卡片”。按店铺和商品内部ID匹配，保留用户成本模拟等信息，并保存整个当前画布。只有保存成功才关闭弹窗；失败/仍在计算的结果不覆盖旧报价；成功空数组代表此次无报价，清空该商品旧报价。

记录浏览器实际采集时间与API原始 downloadedAt，保留原始JSON。金额转换为 units+nanos/1e9。所有报价展示，拒绝原因明确标记，不把 bad-offer-price 计入最低有效报价；不同币种不直接比较。API没有返回商家名称，页面不会虚构商家或保证所有链接都是同款跟卖。单个原始响应也可导入，但没有采集时间时显示“未提供”，店铺歧义时拒绝匹配。画布及输入JSON上限2MB。

本次真实只读验证获取143个商品ID；采集脚本以模拟响应验证串行间隔、限流停止、剪贴板回退。仍需用户在正常浏览器实际运行完成批量采集。

入口：`/desk/ozon-freight-calcula`。不依赖前端框架、在线AI或Excel文件。

## 使用

1. 选择物料（支持物料号、名称搜索和分页），生成卡片。
2. 包装尺寸读取 Item 的 `custom_带包装长度mm`、`custom_带包装宽度mm`、`custom_带包装高度mm`，重量读取 `custom_带包装重量g`。
3. 新卡片货值为 CNY。上方显示1卢布对应人民币的汇率和1500/7000卢布阈值参考，计算时换算卢布判断渠道；汇率可刷新或手动调整，随画布保存。旧画布货值在汇率有效时按原卢布含义换算人民币，不直接把旧数值改称人民币。
4. 点击物料卡片，展开关联的物流报价卡片。默认收起其他物料报价；关闭上方开关可以同时展开多张报价卡片比较。物料卡片始终保留。拖动顶部可自由移动卡片，连线自动跟随。平移时禁止选中文字。
5. 每个物流渠道可以展开查看单位换算、限制检查、体积重、计费重及金额公式。不合规的渠道显示原因，不作为有效报价。
6. 在物流配置弹窗编辑规则，或切换 AI / JSON 编辑导入外部AI整理好的配置。这里只导入结构化数据，不调用AI、不执行字符串公式。应用后需点击保存画布。
7. 保存写入 Ozon Freight Canvas 的三个已有字段。打开按钮可恢复画布，包含参数、卡片位置、物流配置和视角。各画布配置独立。
8. 支持画布及配置JSON导出、导入；最多300物料卡片、500渠道，单份数据2MB。Ctrl+Z / Ctrl+Shift+Z 撤销、重做；空白处拖动平移、滚轮缩放、当前页面全屏。
9. 物料卡片显示只读成本：按可读取的正库存加权估值计算，按公司分开；没有库存时最近采购价只能作为参考，不冒充当前库存成本。查询结果是卡片快照，可刷新。
10. 根据平台物料主表的已启用物料绑定和配置子表 `table_wckx` 的对应 Ozon 店铺，只读调用商品与价格接口。先将Ozon SKU解析到唯一商品，再查询后台 `price.price` 定价，按实际币种转人民币；不会修改Ozon价格。唯一绑定且尚未手填时自动填货值，多绑定需选择。价格查询缓存5分钟，“刷新后台价”可以强制刷新；不会覆盖手填值。
11. 物流配置弹窗为约96%屏幕高度，物流计算卡片高度随屏幕增加；其他页面不受影响。
12. 顶部目标利润率默认35%，百分号放在输入框外。物料→物流→成本计算形成三张关联卡片；成本卡片也可独立拖拽。默认使用最低有效物流报价，可在渠道详情点击“用此运费计算售价”切换。
13. 成本卡片分步显示单件成本、物流、成本覆盖比例、建议售价、佣金和利润校验。目标利润率是扣佣金后利润占售价的比例，售价=（单件成本+运费）÷（1−目标利润率−佣金率），向上取整到分；利润率和佣金之和≥100%时拒绝计算。
14. 从价格接口及商品接口读取SKU对应的FBO/FBS/RFBS/FBP销售佣金百分比。优先匹配物流配置中的履约模式；RETS等非平台履约名称需手动选择佣金模式。没有匹配佣金或唯一人民币库存成本时不计算售价。不同公司成本不擅自合并。
15. 建议售价仅做单件包装估算，不包含税费、广告等未配置成本。建议售价可能跨越运价的货值档位，必须重新核验物流渠道；本版本不会自动迭代或写入Ozon售价。

## 初始运价范围与重要假设

初始46条渠道为历史快照：CEL 18条、兴远15条、RETS 13条。兴远含12条俄罗斯基础渠道及新增俄罗斯、哈萨克斯坦、白俄罗斯邮政渠道。不是自动更新的完整全球运价库，不再依赖原表格文件。

- 全部统一到人民币/千克，原表中的人民币/克费率乘1000。
- CEL、兴远的大件采用体积计费；RETS初始按其俄罗斯表的实际重量公式配置，保留表格差异而非强行统一。
- CEL Premium Big 同时检查文字中150×80×80cm限制，即使原公式未完整检查。
- 兴远550g/2200g/5500g临界点按较小档包含、较大档不包含处理，避免双报价。原表重叠边界需要承运商确认，可修改“下限不含”。
- 未明确允许的带电或液体默认不放行，需确认后编辑配置。
- 初始未设置计费重量进位、附加费；实际存在时请配置。不包含平台佣金、税费、保险和未输入附加费。
- Item 字段名是克，即使存储了0.343这样的数值，也按0.343克读取，不自动猜测为千克，请核对主数据。

## 权限与保护

遵守 ERPNext 单据及物料读取权限，不使用 ignore_permissions。保存已有画布采用数据库行锁和 modified 版本比较，阻止其他窗口静默覆盖。保存期间继续编辑时仍保留未保存标记。页面代码不会修改物料、生成订单或调用Ozon API。

## Cookie、SKU 与跟卖检查（2026-09-17）

- 工具栏“简略展示”后增加 Cookie、刷新 SKU。Cookie 仅 Administrator / System Manager 可保存，按当前用户存入 Frappe 加密凭证存储，不进入画布 JSON、导出文件或页面返回值。无需新增 DocType 字段。
- 刷新 SKU 按店铺分页读取 `/v3/product/list`、`/v3/product/info/list`、`/v5/product/info/prices`；优先匹配现有 ERPNext 物料卡片，再按店铺和商品内部 ID / SKU 匹配自动卡片。只移除匹配的重复自动卡片，不删除用户手工模拟数据。
- 新商品只创建画布卡片，不创建 ERPNext Item 或平台绑定记录。未绑定商品使用 Ozon 图片，包装尺寸和成本留空；新卡片在已有手工卡片右侧纵向排列。所有商品支持 SKU、货号、商品内部 ID 点击复制。画布新增内容仍使用“保存画布”持久化。
- “刷新跟卖”当前仅能检查固定 Ozon 后台价格页面访问情况，并显示带连接线的结果卡片。**尚未识别跟卖明细接口，不能宣称已取得跟卖价格**；HTML 成功响应不等于登录成功。401 或明确登录跳转会要求更新 Cookie，403 不武断判定为过期。
- `document.cookie` 复制按钮仅为提示，它无法读取 HttpOnly Cookie。不要粘贴整段 cURL 或公开凭证。禁止将后台响应 HTML、Cookie 或身份令牌写入画布和日志。后续需在用户授权下定位实际跟卖数据请求，确认参数、登录/防伪要求后再实现明细读取。
- 实际只读验证：当前店铺 143 个商品，分页 100 + 43，均返回 SKU、货号和内部 ID；未保存 Cookie 时正确返回填写提示。新增前端回归测试覆盖重复刷新、手动成本保留、Ozon 图片与失败解锁。
